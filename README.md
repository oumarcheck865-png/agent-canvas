# Agent Canvas

Projet Agent Canvas.

Ce dépôt sert d'environnement de travail principal. Il rassemble les dépôts
externes utilisés comme base technique et de design :

- `vendor/OpenHands` — dépôt officiel OpenHands (https://github.com/All-Hands-AI/OpenHands)
- `vendor/saas-landing-template` — template de landing page SaaS servant de base design (https://github.com/gonzalochale/saas-landing-template)

> Note : les dépôts externes clonés dans `vendor/` sont des références locales.
> Ils ne sont pas commités dans ce dépôt (voir `.gitignore`).
